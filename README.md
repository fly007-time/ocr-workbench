# 识表工作台（网页版）

浏览器内完成 OCR 表格校对、渠道模糊匹配、金额核对及 Excel 汇总。

## 使用

打开 https://fly007-time.github.io/ocr-workbench/ 。导入图片/PDF 后填写自己的智谱 API Key 并点击识别；Excel/Word 可直接进入校对。校对后送入匹配，导入渠道对照表，确认映射并计算汇总，再下载结果。

- API Key 仅保留在当前页面内存，刷新后需重新填写；识别费用由使用者承担。
- 仅主动点击 OCR 识别时，选中的图片（含 PDF 渲染页）会发送至智谱接口。其他解析及汇总在浏览器中完成。
- 下载位置由浏览器决定。多文件 OCR 导出为 ZIP，内部 Excel 使用原文件名（重名追加编号），Sheet 为表1、表2等，不包含说明文字。
- 汇总列沿用 settlement1、settlement2 等；支持单独＋合并、仅单独、仅合并，异常工作表为红色标签。
- 会话不提供历史持久化。离开页面前请导出结果。
- 建议使用最新版 Edge 或 Chrome。真实 OCR 需要可用的智谱密钥和额度。

## 部署与开发

纯静态网页，无后端及构建步骤。GitHub Pages 选择 main 分支根目录发布；资源路径支持仓库子目录。开发时使用任意静态 HTTP 服务器（PDF worker 不建议直接从 file:// 打开）。
